# 预约域业务说明

本文档补充 `docs/domain.md` 中的通用约定在预约域的具体落地。

## 时间与身份

- 所有存储与接口时间均为带时区的 ISO 8601（`+08:00`）；面向用户的通知时间在模板渲染层统一本地化。
- 身份字段不可变：证件号仅以 `idType + 号码` 的 SHA-256 哈希落库，另存掩码用于人工核对；
  同一证件同一时段的唯一有效申请（含候补）通过哈希索引保证。
- 申请编号 `bk_*` 不可猜测；管理令牌为 24 字节随机十六进制，仅创建时返回一次。

## 状态与容量

结构化状态（`held/confirmed/waitlisted/cancelled/expired`）与展示层文本分离；
每次名额变动在审计日志中保存变更前后的用量快照（座位、班次、资源池）。

容量判定为纯函数（`src/booking/capacity.js`），输入当前状态 + 故障集合 + 需求，
输出可行性与具体分片；候补晋级与故障重分配共用同一判定，因此"候补只拿当前空闲容量"
由实现本身保证，不存在任何路径会改动已暂留/已确认申请。

## 服务承诺与故障

- 承诺（班次分片、资源借用）随申请保存为结构化列表，故障时重算并记录
  `service_reassigned / service_unavailable / service_restored` 审计事件，包含命中的
  failover 规则与变更前后对照。
- 无法替代时绝不移动时段名额：承诺摘除、告警留痕、通知提供改期/取消路径。

## 通知

通知 outbox 的幂等键编码业务事件；通知记录包含投递状态、尝试次数与错误信息，
供管理接口审计。工作人员代联接口不暴露手机号，模板内容不包含任何具体需求细节。
